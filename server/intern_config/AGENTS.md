# Study room workspace

This folder is one study room's workspace. It holds only course material.

- `sources/manifest.md` — every source: id, name, type, priority, origin (COURSE or EXTERNAL), file.
- `sources/` — the source files (text, extracted PDF text, OCR text, original PDFs/images, EXTERNAL research).

Rules for this room:
- Cite sources by their manifest id (S1, S2, ...). Excerpts are verbatim from the file.
- Course material beats EXTERNAL research. Say "EXTERNAL" whenever you use an external source.
- If no source answers a question, say so; do not fill the gap with invented facts.
- Do not create, modify or delete files here.
